# Voice Memory для Galaxy Watch (Wear OS)

Standalone-приложение для Samsung Galaxy Watch4 и новее (Wear OS 3+, API 30+).
Два режима работы:

| Режим | Что делает | Как работает |
|---|---|---|
| **Память** | Слушает весь день и запоминает разговоры | Foreground-сервис → VAD (только речь) → разговор уходит одним из двух транспортов (гибрид, см. ниже) → бэкенд: транскрипция, саммари, теги, pgvector |
| **Ассистент** | Слушает и в реальном времени даёт короткие ответы на экране (и голосом в наушники) | Микрофон PCM16 24 кГц → WebSocket `/assist/live` → серверный VAD режет речь на фразы → LLM решает, нужен ли ответ, и стримит его → вибрация + текст (+ TTS) |
| **Сегодня** | «Что я сегодня слышал» | `GET /api/memory/day` → список фрагментов + краткий итог дня от LLM |

Ассистент учитывает и **личную память**: если спросить «когда мы договорились
про демо?», он найдёт ответ в том, что часы слышали раньше (тот же
pgvector-индекс, что и RAG-поиск).

## Гибридный транспорт «Памяти»

Транспорт выбирается **в начале каждого разговора** (`TransportPolicy`) и посреди
разговора не меняется:

| Условие | Транспорт | Что происходит |
|---|---|---|
| На зарядке **или** безлимитный Wi-Fi (и сеть есть) | ⚡ **Вживую** | Стрим в `WS /audio/live?channel=wear-live&vad=1`: сервер режет речь на фразы и сохраняет текст по ходу разговора. Параллельно пишется локальная AAC-копия |
| Иначе (батарея + LTE/через телефон, офлайн) | **Офлайн** | AAC-файл (≤ 1 мин речи или 15 с тишины) → WorkManager → двухфазная загрузка, когда появится сеть |

Надёжность стрима: копия удаляется только после `{"type":"done"}` от сервера.
Обрыв, ошибка или таймаут (120 с) → копия уходит обычной загрузкой, разговор не
теряется. (Если сервер успел сохранить часть, она останется как FAILED-трек и в
«Сегодня» не попадёт.)

Текущий транспорт виден на главном экране: «⚡ Вживую · N» / «Офлайн · N».

**Ручной переключатель** — чип под «Памятью», по тапу по кругу:
**Авто** → **Всегда вживую** → **Всегда офлайн**. По умолчанию — **Всегда вживую**. Выбор сохраняется и
применяется со следующего разговора. «Всегда вживую» без сети всё равно пишет
в офлайн-фрагменты — стримить в пустоту значит потерять разговор.

> Wear OS часто отключает Wi-Fi, пока есть Bluetooth-связь с телефоном, — тогда
> в режиме «Авто» стрим включается в основном на зарядке. «Всегда вживую»
> стримит и через LTE / телефон — быстрее, но дороже по батарее и трафику.

## Голос ответов и расход на прослушивание

- **🔊 Озвучка** — голос генерирует сервер (OpenAI TTS, `ASSISTANT_TTS_VOICE`) и потоком
  шлёт PCM на часы: естественное произношение, смешанные языки, первый звук ≈ 1 с
  после ответа. Если сервер это отключил (`ASSISTANT_SERVER_TTS=false`) — голос часов.
- **Без эха:** пока звучит ответ (и 0.6 с после), микрофон не отправляется; сервер
  дополнительно игнорирует фразы, повторяющие недавний ответ.
- **Только речь:** ассистент шлёт на сервер лишь фрагменты с речью (+0.3 с до и 1 с
  после) — распознавание оплачивается за секунды звука, а тишина больше не стоит денег.

## Когда на сервере нет кредитов ИИ

Сервер отличает «нет кредитов OpenAI» (`insufficient_quota`) от обычных сбоев и
сообщает часам код `ai_unavailable` (WS-события и `GET /api/memory/status`).

- **Ассистент** останавливает микрофон и пишет «ИИ недоступен на сервере».
- **Память** продолжает писать **только локально** (без стрима и загрузок) и
  показывает предупреждение на главном экране.
- Раз в несколько минут часы перепроверяют статус (сервер делает 1-токенный
  запрос не чаще раза в 5 минут); как только кредиты появились — всё накопленное
  загружается само.

## Быстрый запуск ассистента кнопкой

Приложение ставит два значка: **Voice Memory** и **VM Ассистент**. Второй сразу
открывает ассистента, и тот начинает слушать.

- **Двойное нажатие нижней кнопки:** *Настройки → Дополнительные функции →
  Настройка кнопок → Двойное нажатие* → выбрать **VM Ассистент**.
- **Долгое нажатие:** приложение объявлено голосовым помощником (`ASSIST`). Если
  прошивка разрешает, его можно выбрать вместо Bixby/Gemini в том же меню или в
  *Приложения → Приложения по умолчанию → Цифровой помощник*.
- Для отладки: `adb shell am start -n com.voicememory.wear/.ui.MainActivity --es open assist`.

## Тема разговора

Кнопка **«Тема»** на экране ассистента: *Без темы, IT-собеседование, Работа (IT), Учёба,
Медицина, Покупки*. Тема меняет, как ассистент понимает услышанное: на
**IT-собеседовании** фразы — вопросы интервьюера, и они трактуются так, как их задают
на собеседованиях («паттерн на каждую букву SOLID» → какие паттерны реализуют каждый
принцип), а ответ — тезисами, которые можно сразу произнести. Тема также подсказывает
распознаванию речи профильные термины. Выбор запоминается.

## Режимы ассистента

- **Авто** — сам отвечает, когда в разговоре звучит вопрос, просьба о факте,
  числе, дате, переводе или явно неверное утверждение. На болтовню молчит
  (модель возвращает `[SKIP]`, ответ не показывается — одно LLM-обращение
  вместо двух: классификация + ответ).
- **По тапу** — только слушает; кнопка «Ответить» даёт подсказку по последней теме.
- **Озвучка** — ответ читается через TTS (удобно с Galaxy Buds).
- Пока ассистент открыт, «Память» ставится на паузу (один микрофон), а сам
  разговор сохраняется в память (`save=1`), так что ничего не теряется.

## Сборка

Нужен Android Studio (Ladybug+) или Android SDK 35 + JDK 17.

```bash
cd wear-os
cp local.properties.example local.properties   # заполнить sdk.dir, baseUrl, hmacSecret
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

`voicememory.hmacSecret` должен совпадать с `DEVICE_HMAC_SECRET` на бэкенде.
Значения также можно передать через env `VOICEMEMORY_BASE_URL`,
`VOICEMEMORY_HMAC_SECRET`, `VOICEMEMORY_LANGUAGE` (для CI).

### Установка на часы

1. На часах: *Настройки → О часах → Сведения о ПО* → 7 раз тапнуть «Версия ПО»
   → появятся *Параметры разработчика* → включить **Отладка ADB** и **Отладка по Wi-Fi**.
2. `adb pair <ip>:<port>` (код сопряжения на часах), затем `adb connect <ip>:<port>`.
3. `./gradlew :app:installDebug`.

## Проверка с бэкендом на своём компьютере (debug-сборка)

Без пересборки APK: часы ходят на `localhost:3000`, а `adb reverse` пробрасывает
этот порт на компьютер (работает и по USB, и по Wi‑Fi-отладке).

```bash
# 1. бэкенд локально, DEVICE_HMAC_SECRET в .env = секрет, который передадим часам
docker compose up -d && npm run build && npm run migrate && npm start

# 2. проброс порта часы → компьютер (повторять после каждого adb connect)
adb reverse tcp:3000 tcp:3000

# 3. указать приложению адрес и секрет (только debug; -S перезапускает процесс)
adb shell am start -S -n com.voicememory.wear/.ui.MainActivity \
    --es baseUrl http://localhost:3000 --es hmacSecret <DEVICE_HMAC_SECRET>
```

Debug-сборка разрешает `http://` (`src/debug/AndroidManifest.xml`); release — только HTTPS,
и переопределение адреса через adb в release игнорируется.

## Архитектура

```
ui/            Compose for Wear: Home · Assistant · Today (MVVM, StateFlow)
assist/        AssistSession (mic → WS), AssistEventReducer (чистый редьюсер протокола),
               AnswerFeedback (вибро + TTS)
memory/        MemoryRecorderService (foreground, type=microphone, OngoingActivity),
               TransportPolicy + DeviceConditionsMonitor (зарядка / Wi-Fi),
               sink/: SegmentSink (Strategy) → FileSegmentSink | LiveSegmentSink (стрим + копия),
               SegmentStore (контракт имён файлов), SegmentUploadWorker (WorkManager)
audio/         PcmRecorder (Flow<ShortArray>), VoiceActivityDetector, SegmentPolicy,
               AacFileEncoder (MediaCodec → .m4a)
auth/          DeviceSigner (HMAC как в DeviceAuthGuard / WsHmacAuthService)
net/           VoiceMemoryApi (Facade над REST/WS)
AppContainer   ручной DI / composition root
```

Чистая логика (`SegmentPolicy`, `TransportPolicy`, `VoiceActivityDetector`, `DeviceSigner`,
`AssistEventReducer`) не зависит от Android и покрыта JVM-тестами; тест
`DeviceSignerTest` использует векторы, посчитанные Node `crypto`, — гарантия
совместимости подписи с бэкендом.

## Батарея и приватность — важно

- Постоянная запись = микрофон + partial wake lock весь день. Энергетический
  VAD дешёвый, а в сеть уходит только речь (AAC 32 кбит/с ≈ 240 КБ/мин), но
  рассчитывайте на заметно меньшее время работы часов. Загрузка идёт только
  при `batteryNotLow`.
- Режим ассистента стримит звук постоянно (~48 КБ/с) — используйте его точечно.
- Запись окружающих людей регулируется законом (во многих странах нужно
  согласие всех участников). Предупреждайте собеседников.
- Общий `DEVICE_HMAC_SECRET` вшивается в APK — это та же модель доверия, что у
  IoT-рекордера. Для публичного распространения нужна персональная выдача
  ключей устройству (provisioning) — отдельная задача.
